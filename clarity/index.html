Cara upload hasil ke TikTok StudioMICROSOFT EDGE

Setelah video selesai diproses, upload lewat TikTok Studio di Microsoft Edge supaya alurnya konsisten dan gampang diikuti.

01Login TikTok di Microsoft Edge

Buka tiktok.com di Microsoft Edge lalu login ke akun TikTok yang mau dipakai upload.

02Aktifkan mode desktop

Kalau dari HP atau tablet, buka menu Edge lalu aktifkan Situs desktop / Desktop site. Di PC atau laptop, langkah ini bisa dilewati.

03Buka TikTok Studio

Masuk ke TikTok Studio lewat browser yang sama supaya sesi login tetap aktif.

04Upload video hasil

Pilih file hasil dari TikTok Method, cek caption dan preview, lalu lanjutkan upload dari TikTok Studio.

TikTok tetap dapat melakukan kompresi setelah file dikirim. Tutorial ini mengatur jalur upload, bukan menjamin TikTok tidak akan memproses ulang video.Buka TikTok Studio ↗
